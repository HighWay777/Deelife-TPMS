### Deelife TPMS v1.12 — In-App Updates

From this version on, the app checks this repository for new releases and offers to update itself over the head unit's internet connection (Wi-Fi or hotspot). Android always asks you to confirm the installation.

#### ⚠️ One-time manual step when coming from v1.11
v1.12 is signed with the project's new permanent release key, so Android cannot install it over v1.11:
1. Uninstall the old **TPMS** app (v1.11).
2. Install `Deelife-TPMS-v1.12.apk` below.
3. Re-check your settings (units, thresholds, calibration). Sensor pairing is stored in the USB receiver and is kept.

Every later version will install over v1.12 from the in-app update dialog.

#### New
- **Automatic update check** at most every 6 hours, plus a **Check for Updates** button in Settings → App Updates (auto-check can be switched off).
- Update dialog with release notes, download progress, *Later* and *Skip this version*. It never covers an active tyre alarm.
- Downloads can resume and are verified by SHA-256 before installing. Monitoring restarts automatically after the update.

#### Fixes
- USB monitoring now keeps reconnecting after a read error. Before, it stayed dead after the first 3 minutes until the app was reopened.
- Fixed a crash on Android 14+ when the app requests USB permission.
- Android 14+: the background service can start after boot before USB permission is granted.
- A tyre card no longer shows "snoozed" while a (never snoozable) fast-leak alarm is sounding.
- Fixed a race that could reset the pairing wizard step, a MediaPlayer leak and unsynchronised alarm evaluation.
- The APK is ~40% smaller (proper release build, unused image removed).
